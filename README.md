# ClaseReact

Este proyecto reúne una guía práctica de aprendizaje de React usando Vite. La idea principal es mostrar de forma sencilla conceptos fundamentales del framework mediante ejemplos interactivos y navegación entre temas.

## ¿Qué incluye?

La aplicación está desarrollada en la carpeta vite-react y contiene ejemplos de:

- Componentes funcionales y de clase
- Props
- State y useState
- useEffect
- Renderizado condicional
- Listas y keys
- Navegación entre rutas con React Router

## Estructura del proyecto

- ClaseReact/
  - vite-react/ : proyecto principal de React + Vite
    - src/components/ : componentes de ejemplo para cada tema
    - src/App.jsx : configuración de rutas
    - src/App.css y src/index.css : estilos de la interfaz

## Requisitos

- Node.js 18 o superior
- npm

## Instalación

Desde la carpeta del proyecto:

```bash
cd ClaseReact/vite-react
npm install
```

## Ejecución

Para correr la aplicación en modo desarrollo:

```bash
npm run dev
```

Luego abre la URL que muestra Vite en el navegador.

## Scripts disponibles

- npm run dev : inicia el servidor de desarrollo
- npm run build : genera la versión de producción
- npm run preview : previsualiza la build generada
- npm run lint : revisa el código con ESLint

## Objetivo del proyecto

Servir como material de estudio para comprender los fundamentos de React de una manera visual y práctica.
